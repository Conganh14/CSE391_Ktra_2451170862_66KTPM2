# Task List App

Ứng dụng quản lý công việc đơn giản sử dụng HTML, CSS và JavaScript thuần.

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5

## Chức năng

- Hiển thị danh sách Tasks được tải từ `data.json`
- Thêm Task mới với validation: tên không được để trống và không quá 100 ký tự
- Phân loại độ ưu tiên: High, Medium, Low
- Hiển thị trạng thái Task: Done, In Progress

## Cấu trúc thư mục

```

├── index.html
├── main.js
├── data.json
└── bootstrap/
├── css/
│ └── bootstrap.min.css
└── js/
└── bootstrap.bundle.min.js

```
